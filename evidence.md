Not found in any field of the three exports: an e-mail address, a user name, a user or account id field, a token, a cookie, an `Authorization` or `Set-Cookie` header, a session id, a wallet address, an IP address or a request id. Because the first line of each export was edited, the shipped exports' SHA-256 are not those of the files the runner wrote (they are in MANIFEST, Dataset and capture, and in E10 to E12); the converter's input list and E01's `meta.captures` name the shipped copies, and Step 19's converter rerun reproduces E01 from them byte for byte.
